# Joan Achieng Abwao – Interactive Portfolio

Modern dark-themed interactive portfolio matching the style of the [Data Analysis Manual](https://abwaojoan.github.io/data-analysis-manual/).

**Live URL (after enabling Pages):**  
https://abwaojoan.github.io/joan-abwao-portfolio/

## Features
- Fixed dark sidebar navigation (like the Manual)
- Gradient hero with animated orbs + grid
- Filterable project cards
- QGIS study-site map gallery
- Fully responsive (mobile menu)
- Smooth scroll + active section highlighting

## How to update your existing GitHub repo

1. Download / unzip this folder
2. Go to https://github.com/abwaojoan/joan-abwao-portfolio
3. Click **Add file → Upload files**
4. Drag **all** files and folders from this portfolio (index.html, css/, js/, assets/, README.md)
5. Commit changes
6. Wait 1–2 minutes → open https://abwaojoan.github.io/joan-abwao-portfolio/

Make sure `index.html` is in the **root** of the repository (not inside another folder).
